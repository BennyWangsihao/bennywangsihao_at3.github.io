Prototype Concept

Scrollscape uses scroll as the main browser interaction. Instead of clicking buttons or navigating to different pages, the user scrolls through calm visual moods. The background, progress bar, animated shapes and text transitions all respond to the scroll position.

Sources

No external images, audio, fonts or JavaScript libraries are used. All visuals are created with original HTML, CSS and JavaScript.
