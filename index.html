Prototype Concept

Scrollscape uses scroll as the main browser interaction. Instead of clicking buttons or navigating to different pages, the user simply scrolls to move through calm visual moods. The changing background, progress bar, animated shapes and fade-in text all respond to the user's scroll position.

Sources

No external images, audio, fonts or JavaScript libraries are used. All visual elements are created with original HTML, CSS and JavaScript.
