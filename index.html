Concept

Scrollscape uses scroll as the main browser interaction. The user moves through a quiet time room, and each section represents a different stage of focus. The background, card animation, progress bar and visual symbols all respond to the scroll position.

Draft Explanation

This is a prototype version. The main focus is testing how scrolling can guide the user through different moods. The text and section names can be developed further later, but the interaction structure is already working.

Reference Websites

I looked at Calm because it connects to relaxation and focused study. Calm uses soft colours, simple spacing and a peaceful visual style.

I also looked at Apple product pages because they often use scrolling to reveal information step by step. This inspired the way each section appears one at a time.

The third reference is New York Times interactive stories. These stories often use scroll to guide the reader through a visual journey, which helped me think about scroll as more than just page movement.
